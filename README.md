# 奶龙公众号排版与配图

这是一个可复用的 Codex skill，用于奶龙、牛来、肥嘟嘟主题的微信公众号文章排版、插图和封面制作。

## 重点

- 以用户最新提供的形象图为最高优先级，严格区分奶龙、牛来和肥嘟嘟，不串脸。
- 画面中突出的物件默认带奶龙脸；牛来和肥嘟嘟始终保留自己的脸。
- 保留文章原文；按情节规划不重复、与段落对应的图片。
- 多图任务在可用时并行生成，并在交付前核对角色、图文对应和图片内嵌情况。
- 奶龙表情和姿势随场景变化；大笑参考图保存在角色素材目录。
- 需要公众号封面时接入 `$wechat-cover-ai` 技能。
- 不输出作者名/简介占位符；默认使用用户指定的固定收尾句。
- 节日装饰、特定画风和“物件也长奶龙脸”等要求只用于用户指定的单篇内容。

## 安装

将本仓库克隆或复制到 Codex skills 目录，例如：

```text
~/.codex/skills/nailong-gzh-studio/
```

技能入口为 `SKILL.md`；角色细节见 `references/character-bible.md`，参考图保存在 `assets/characters/`。
